## これは何か

論文や専門書のPDFを読むための、Windows向けデスクトップアプリです。

本文をドラッグすると、その場で**辞書**を引いたり**翻訳**したりできます。引いた語は**単語帳**に、訳した段落は**対訳メモ**として手元に貯まります。マーカーを引いた位置も本ごとに覚えます。

アカウント登録もログインも要りません。**読んだ本も書き込みも、すべてご自分のPCの中だけ**に保存されます。

## インストール

1. [Releases](../../releases/latest) から `Bunkengura-Setup-x.y.z.exe` をダウンロード
2. ダブルクリックして、画面に従って進めてください

> [!NOTE]
> **「WindowsによってPCが保護されました」と出たら**
>
> このインストーラにはコード署名証明書を付けていません（個人開発のため）。初回は Windows SmartScreen が警告を出します。
> 続ける場合は「**詳細情報**」→「**実行**」を押してください。警告が気になる場合は、下の「ソースから自分でビルドする」でご自身の手元から作れます。

管理者権限は要りません（ユーザー単位でインストールされます）。

## 最初の設定

辞書引きと翻訳には **Anthropic の APIキー** が要ります。

1. [Anthropic コンソール](https://console.anthropic.com/settings/keys) でキーを発行します
2. アプリの「設定」画面に貼り付けて保存します

キーはこのPCの中（OSの暗号化領域）にだけ保存され、Anthropic 以外のどこにも送られません。**料金は使った分だけご自身に請求されます。**

モデルは設定画面で選べます。辞書引きを何度も使うなら、速くて安い Haiku が快適です。

| モデル | 目安の料金（100万トークンあたり） |
|---|---|
| Opus 5.5（既定・最も賢い） | 入力 $4 / 出力 $20 |
| Sonnet 5.5 | 入力 $2 / 出力 $10 |
| Haiku 5.5（最も速い・安い） | 入力 $0.10 / 出力 $0.50 |

> APIキーが無くても、**本を読む・マーカーを引く・単語を手で書き留める**ことはできます。

## できること

- **PDFの取り込み** — 文字情報を持つPDF（OCR済みを含む）からテキストを取り出して本棚に並べます
- **リーダー** — 文字サイズ・行間・余白・配色（紙／白／セピア／夜）を調整できます。しおりは自動で残ります
- **辞書** — 1語を選ぶと、発音・一般的な意味・専門的な意味・例文、さらに「その文での使われ方」を返します
- **翻訳** — 段落を選ぶと日本語訳が出ます。メモを添えて対訳メモに残せます
- **単語帳** — 引いた語が出典文つきで貯まります。CSVで書き出せます
- **対訳メモ** — 本ごと・ページ順に並べて読み返せます
- **マーカー** — 赤・黄・青 × 塗り／下線。右クリックで下線になります
- **ページ内検索** — `Ctrl+F`。大小文字を区別せず、語句（空白をまたぐ語）も探せます

### 対応していないPDF

紙をスキャンしただけで**文字情報を持たないPDF**は、本文を取り出せません。取り込み時にその旨をお知らせします。あらかじめ OCR をかけたPDFをご用意ください。

## データの置き場所

すべて下記の中にあります。バックアップはこのフォルダごと控えてください。

```
Windows:  %APPDATA%\bunkengura-desktop\
macOS:    ~/Library/Application Support/bunkengura-desktop/
Linux:    ~/.config/bunkengura-desktop/
```

| ファイル | 中身 |
|---|---|
| `library.json` | 蔵書の目録 |
| `books/<id>.txt` / `books/<id>.pdf` | 取り出した本文と、元のPDF |
| `vocabulary.json` | 単語帳 |
| `translation-memos.json` | 対訳メモ |
| `markers.json` | マーカー |
| `settings.json` | 設定（APIキーは暗号化して保存） |

アプリをアンインストールしてもこのフォルダは残ります。完全に消したい場合は手で削除してください。

## 外部と通信する場面

このアプリが外に出るのは、**辞書引きと翻訳のときに Anthropic API を呼ぶときだけ**です。

送られるのは、選んだ語句とその前後の文だけです。利用状況の収集や広告の類は一切ありません。APIキーを設定しなければ、アプリは一度も外部通信しません。

## ソースから自分でビルドする

必要なもの: Node.js 20 以上

```bash
git clone https://github.com/hidetako/bunkengura-desktop.git
cd bunkengura-desktop
npm ci

npm run dev        # 開発用に起動する
npm run pack:win   # Windows用インストーラを release/ に作る（Windows上で実行）
```

Windows用インストーラは Windows 上でしか作れません。このリポジトリでは、`v1.2.3` のようなタグを push すると GitHub Actions の Windows ランナーがビルドして Releases に貼ります。

## つくり

| 層 | 中身 |
|---|---|
| 画面 | React 18 + Vite。`src/` |
| 本体 | Electron のメインプロセス。`electron/` |
| 橋渡し | `contextBridge` 経由の型付きIPC。`shared/api.ts` に形を定義 |

APIキーと Anthropic への通信はすべてメインプロセス側にあります。画面側のコードはキーに触れません。

本文の位置合わせ（マーカーや対訳メモを、再び開いたときに同じ場所へ当てる処理）は `src/lib/text-marker.ts` にあります。PDF抽出のゆれ（合字・ハイフネーション・空白の差）を吸収するため、前後の文字列と概略位置を手がかりに出現箇所を選びます。

## Web版との関係

同じ作者による [文献蔵 Web版](https://github.com/hidetako/bunkengura-web) があります。あちらは Google アカウントでログインし、スプレッドシートに保存して複数端末で同期する作りです。PubMed検索や論文リーダーも載っています。

このデスクトップ版は、**ログインも同期も無しに、1台のPCで完結して読むこと**に絞ったものです。
